# AISTVM — Windows Cloud tức thì

Khởi chạy môi trường Windows trên cloud để học tập, kiểm thử và debug từ mọi nơi.

## Điểm nổi bật

- Windows cloud riêng cho từng phiên làm việc.
- Kết nối an toàn qua Tailscale và RDP.
- Monitor CPU, RAM và ổ đĩa theo thời gian thực.
- Tự động dọn dẹp tài nguyên sau khi phiên kết thúc.
